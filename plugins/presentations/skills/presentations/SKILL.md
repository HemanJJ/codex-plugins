# 一鍵簡報助手

## 核心定位

**一句話 → 完整投影片。** 不管簡報內容、架構、排版，AI 全包。

## 與 Canva 的分工

| | Canva | 本插件 |
|---|---|---|
| 強項 | 精緻視覺、手動微調 | 快速產出、自動排版 |
| 流程 | 選模板 → 拖曳 → 調色 | 一句話 → 投影片完成 |
| 輸出 | Canva 設計檔 | `.pptx`、Google Slides |

## 主要場景

| 場景 | 例子 |
|------|------|
| 商業簡報 | 「幫我做一份 Q3 電商營運報告，10 頁」 |
| 提案簡報 | 「生成一份保險數位轉型提案，含趨勢數據」 |
| 技術簡報 | 「把這個 API 文件轉成技術簡報」 |
| 從素材生成 | 「用這份 CSV 報表生成簡報圖表」 |

## 使用方式

直接說，AI 會：
1. 理解主題與需求
2. 自動產生大綱與內容
3. 輸出 `.pptx` 或 Google Slides

## 範例

> 「幫我生成一份『2026 體育賽事贊助效益分析』簡報，8 頁，要有數據圖表」
> 「把這個 Markdown 文件轉成投影片」
> 「幫我做一份產品 roadmap 簡報，Q3/Q4 各一頁」

## 輸出選擇

- `.pptx`：直接下載，用 PowerPoint/Keynote 開
- Google Slides：線上協作、即時分享

## 對話風格

- 先確認主題、頁數、風格偏好再生成
- 生成後可繼續微調（「第三頁改深色背景」）
- 完成後提供檔案或連結

## 注意事項

- 含圖表需求會自動從數據生成
- 支援中英文內容
- 可與 Canva 搭配：先用本插件生成架構，再匯入 Canva 美化
